# AutoMouseMover

키오스크 PC에서 마우스 커서를 일정한 주기마다 화면의 임의 위치로 옮기는 작은 Windows 프로그램입니다.

실행하면 화면에 아무것도 띄우지 않고 백그라운드에서 동작합니다. 기본으로 50초마다 커서를 화면 안의 임의 위치로 옮기며, 이 이동은 실제 마우스를 움직였을 때와 같은 입력으로 처리됩니다.

> [!WARNING]
> 이 프로그램은 키오스크 전용으로 만들었습니다. 일반 업무용 PC에서 실행하면 작업하는 도중에도 커서가 주기적으로 다른 위치로 옮겨지고, 로그인할 때마다 자동으로 다시 실행됩니다.

## 특징

- 설치 과정이 없고, 별도의 런타임도 필요하지 않습니다. C 런타임은 실행 파일 안에 정적으로 포함되며, 나머지는 Windows에 기본으로 들어 있는 DLL만 사용합니다.
- 실행 파일의 크기는 100KB 정도입니다.
- 창, 트레이 아이콘, 콘솔을 띄우지 않습니다.
- 실행하는 즉시 로그인할 때 자동으로 실행되도록 등록됩니다.
- 커서를 옮길 때만 잠깐 동작하므로 CPU를 거의 사용하지 않습니다.
- 모니터를 여러 대 연결했다면 모든 모니터를 합친 영역에서 위치를 고릅니다.
- 클릭이나 키 입력은 보내지 않고, 커서의 위치만 바꿉니다.

## 요구 사항

- Windows 11 x64
- ARM64 기반 Windows 11에서는 x64 에뮬레이션으로 실행됩니다.

## 사용법

`AutoMouseMover.exe`를 키오스크 PC의 고정된 위치에 복사한 다음 실행합니다.

| 명령 | 동작 |
| --- | --- |
| `AutoMouseMover.exe` | 50초마다 커서를 옮깁니다. |
| `AutoMouseMover.exe 30000` | 30초마다 커서를 옮깁니다. |
| 실행 중에 한 번 더 실행 | 실행 중인 인스턴스를 종료합니다. |

이동 주기는 밀리초 단위로 지정하며, 1000(1초)부터 3600000(1시간)까지 쓸 수 있습니다. 이 범위를 벗어난 값은 가장 가까운 경계값으로 바뀝니다. 인수를 생략하거나 0 또는 숫자가 아닌 값을 넣으면 50초 주기로 동작합니다.

첫 이동은 실행한 시점에서 한 주기가 지난 뒤에 일어납니다. 한 번에 하나의 인스턴스만 실행되며, 프로그램을 종료하면 커서는 마지막으로 옮겨진 위치에 그대로 남습니다.

## 입력이 없을 때 작동하는 기능

커서 이동은 실제 마우스 입력과 같은 방식으로 처리됩니다. 따라서 이동 주기가 아래 기능의 대기 시간보다 짧으면, 아무도 PC를 조작하지 않아도 해당 기능이 작동하지 않습니다.

- 화면 보호기
- 화면 끄기와 절전 모드
- 일정 시간 동안 입력이 없으면 화면을 잠그는 정책
- 마우스 움직임을 감지해서, 입력이 없으면 처음 화면으로 돌아가는 웹 페이지나 프로그램

## 자동 실행

프로그램은 실행될 때마다 다음 위치에 자신을 등록합니다. 현재 사용자 영역에 기록하므로 관리자 권한이 필요하지 않습니다.

```
HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run
값 이름: AutoMouseMover
```

- 실행할 때 지정한 이동 주기도 함께 기록되므로, 로그인할 때도 같은 주기로 실행됩니다.
- 실행 파일을 다른 위치로 옮긴 경우에는 새 위치에서 한 번 실행하면 등록된 경로가 갱신됩니다.
- 실행 중인 인스턴스를 종료해도 등록은 해제되지 않습니다.

자동 실행을 중지하려면 작업 관리자의 **시작 앱** 탭이나 **설정 > 앱 > 시작 프로그램**에서 `AutoMouseMover`를 끕니다. 이렇게 끈 설정은 프로그램을 다시 실행해도 유지됩니다. 등록 자체를 삭제하려면 다음 명령을 실행합니다.

```cmd
reg delete "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" /v AutoMouseMover /f
```

## 동작 방식

1. 이름 있는 이벤트 객체를 만들어서 다른 인스턴스가 실행 중인지 확인합니다. 이미 실행 중이면 그 인스턴스에 종료 신호를 보내고 곧바로 끝납니다.
2. 자동 실행 항목을 등록합니다.
3. 화면에 보이지 않는 창을 만들고, 지정한 주기마다 울리는 타이머를 설정합니다.
4. 타이머가 울릴 때마다 모든 모니터를 합친 영역에서 임의의 좌표를 하나 고르고, 그 좌표로 마우스 이동 입력을 보냅니다. 좌표는 화면 해상도나 배율의 영향을 받지 않는 정규화 좌표로 지정합니다.
5. 다른 인스턴스가 보낸 종료 신호를 받으면 숨겨진 창을 닫아 프로그램을 끝냅니다.

## 제한 사항

- 사용자가 키오스크를 조작하는 중이어도 주기가 되면 커서를 옮깁니다. 마우스 버튼을 누른 채 끌고 있을 때 커서가 옮겨지면, 끌기 동작이 의도하지 않은 위치로 이어질 수 있습니다.
- 커서가 옮겨진 위치에 있는 웹 페이지 요소에는 마우스를 올렸을 때와 같은 효과가 나타날 수 있습니다. 예를 들어 메뉴가 펼쳐지거나 도구 설명이 표시될 수 있습니다.
- 터치 화면에서는 터치로 조작하는 동안 마우스 커서가 숨겨지는데, 이 프로그램이 커서를 옮기면 커서가 다시 나타납니다.
- 모니터의 해상도나 배치가 서로 달라서 모니터 사이에 빈 영역이 있다면, 그 영역의 좌표가 골라졌을 때 커서는 가장 가까운 모니터의 가장자리로 옮겨집니다.
- 잠금 화면, 로그인 화면, 사용자 계정 컨트롤(UAC) 확인 창이 표시되는 동안에는 커서를 옮기지 못합니다.
- 관리자 권한으로 실행된 프로그램의 창이 앞에 있으면 Windows가 이동 입력을 막을 수 있습니다. 이 경우 이 프로그램도 관리자 권한으로 실행해야 합니다.
- 실행 파일에 코드 서명이 없습니다. 그래서 Windows Defender 같은 백신이 작은 실행 파일을 악성으로 잘못 판단할 수 있습니다. 브라우저에서 내려받은 파일이라면 차단되거나 격리될 수 있으며, 이 경우 파일을 직접 복사해서 쓰거나 백신 예외로 등록해야 합니다.

## 빌드

다음 도구가 필요합니다.

- Visual Studio 또는 Build Tools의 **C++를 사용한 데스크톱 개발** 워크로드 (MSVC 컴파일러와 Windows SDK)

저장소 폴더에서 `build.cmd`를 실행하면 `bin\AutoMouseMover.exe`가 만들어집니다. 스크립트가 `%ProgramFiles%`와 `%ProgramFiles(x86)%`에서 설치된 Visual Studio를 찾아 빌드 환경을 스스로 구성합니다.

표준 MSVC 컴파일러와 링커로 빌드하고 C 런타임을 실행 파일 안에 정적으로 포함하므로, 재배포 패키지를 따로 설치할 필요가 없습니다. 버전 정보는 `src/app.rc`에 들어 있습니다.
